## LIVE 수신과 제약

Vehicle/AAOS/NaviHelper에서 속도 0, 브레이크 false, 방향지시등 OFF, P 기어, 조작 허용, 기본 내비 위치 응답을 읽었습니다. 활성 실제 경로는 등록하지 않았으므로 LIVE 구간 판정과 안내는 실행하지 않았습니다. 해당 수신은 연결 확인이며 차량 변화 추적 검증이 아닙니다.

Virtual Console은 adb forward tcp:8088 tcp:8088 이후 http://127.0.0.1:8088 에서 열렸습니다. 상태 변경 요청은 HTTP 503과 emulator_inactive를 반환했고, 상태 응답의 DDS bridge는 비활성 상태였습니다. Cold Boot와 WHPX 사용을 확인했지만 이 환경의 브리지 비활성 원인은 확정하지 못했습니다. 시스템의 제한된 car_service 조작은 사용하지 않았습니다.
