# 동행 개발 구조

- app: Kotlin / Jetpack Compose Android 앱, 네 화면, 로컬 저장, 녹음 음성, Pleos·AAOS 연결.
- core: Android에 의존하지 않는 구간 판정, 안내 정책, 시나리오 재생, 단위 테스트.
- 플랫폼 데이터 → Snapshot → CoachEngine → 화면·기록·음성의 단방향 흐름.

## 시연과 실제 데이터

시나리오 재생은 합성 입력이다. 실제 연결과 같은 판단 엔진을 거치지만 출처를 항상 표시하고 기록을 분리한다. 실시간 연결은 Vehicle SDK / NaviHelper / AAOS에서 실제 관찰한 값을 전달한다. 구독 성공을 값 수신 성공으로 표시하지 않는다. 지정한 실제 경로가 없으면 구간 안내를 시작하지 않는다.

## 기록 규칙

첫 주행은 두 후보 구간을 기록한다. 사용자가 복습 후 구간·이유·목표·도움 단계를 고른다. 최근 두 기록은 동일 출처, 구간, 접근 방향끼리 비교한다. 누락 또는 오래된 속도·페달·신호는 정상값으로 대체하지 않는다. 속도 그래프는 구간 진입 시점을 0초로 한다.

## 안내 규칙

선택한 목표는 한 구간에 하나이다. 방향지시등이 이미 일치하면 신호 확인 목표만 생략한다. 회전 예습 목표는 신호 상태만으로 완료 판정하지 않는다. 속도 목표는 주행 후 복습한다. 구간당 안내는 최대 한 번이며 위치·경로 불확실성, 반대 접근, 경로 취소는 안내를 보류한다. 음성 포커스가 거부되거나 상실되면 뒤늦게 재생하지 않는다.

## 제품 한계

이 프로토타입은 운전 점수, 안전성 인증, 적정 회전 속도, 주변 차량 판단, 조향·제동 명령을 제공하지 않는다. 기본 내비가 경로 안내를 담당한다. 사용자 평가와 관찰 기록은 분리해서 보여준다. 실제 연동은 해당 에뮬레이터 및 기본 내비에서 검증해야 한다.
